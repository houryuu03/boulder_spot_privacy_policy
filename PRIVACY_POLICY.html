BolSpot プライバシーポリシー

最終更新日: 2026年8月20日

〔開発者名〕（以下「当方」）は、iOS アプリ「BolSpot」（以下「本アプリ」）におけるユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリは、機能の提供のために以下の情報を取得・保存します。

1.1 アカウント情報

  • メールアドレス、ニックネーム（表示名）：アカウントの作成・認証・本アプリ内での表示に使用します。メールアドレスは、メールアドレスでの登録時、または Sign in with Apple でのサインイン時に Apple から提供される情報として取得します。Apple の「メールを非公開」機能を選択した場合は、Apple の中継（プライベートリレー）アドレスを取得します。
  • パスワード：メールアドレスで登録したアカウントについて、認証基盤（Firebase Authentication）が安全に管理します。当方が平文のパスワードを保持することはありません。（Sign in with Apple を利用する場合、本アプリはパスワードを扱いません。）

1.2 ユーザーが作成・登録する情報

  • プロフィールアバター：あらかじめ用意されたプリセットから選択します（画像のアップロードは行いません）。
  • ジムのレビュー（5項目の星評価）
  • セッション募集（掲示板）への公開情報（訪問予定に基づくジム名・日時・コメント・参加状況）
  • お気に入りジム / ホームジム
  • 月間課題の完登・トライ記録・メモ
  • ブロックしたユーザーの一覧（不快なユーザーのコンテンツを非表示にするために使用）

1.3 端末・通知・広告に関する情報

  • プッシュ通知トークン（FCM トークン）：ジムの営業予定カレンダー更新の通知を送るために使用します。
  • 位置情報：現在地周辺のジム検索・地図表示のために使用します。位置情報は端末内での処理にのみ使用し、当方のサーバーへ送信・保存しません。
  • 広告識別子（IDFA）等：本アプリの無料版では広告（Google AdMob）を表示します。パーソナライズ広告の配信・計測のため、iOS の「トラッキングの許可」（App Tracking Transparency）でユーザーが許可した場合に限り、広告識別子等の端末情報が広告事業者（Google）によって取得・利用されることがあります。許可しない場合は、パーソナライズされない広告が表示されます。プレミアム（有料）にアップグレードすると、広告は表示されません（下記 3 参照）。

1.4 トラッキングについて

  • 本アプリは、当方独自の行動追跡（トラッキング）や分析（アナリティクス）は行いません。
  • 広告のための識別子の利用は、上記 1.3 のとおり、ユーザーの ATT 許可設定および広告事業者（Google）のポリシーに従います。トラッキングの許可・不許可は、iOS の「設定 > プライバシーとセキュリティ > トラッキング」からいつでも変更できます。

2. 利用目的

取得した情報は、以下の目的で利用します。

  • 本アプリの機能（ジム検索、レビュー、掲示板、課題管理、通知等）の提供
  • アカウントの認証・管理
  • 広告の表示（無料版）
  • ユーザーサポートおよびお問い合わせへの対応
  • 不適切なコンテンツ・迷惑行為への対応（通報対応・アカウント停止等）
  • 本アプリの品質・安全性の維持・向上

3. 第三者サービスの利用

本アプリは、以下の外部サービスを利用します。これらのサービスにおける情報の取り扱いは、各社のプライバシーポリシーに従います。

  • Google Firebase（Authentication / Cloud Firestore / Cloud Functions / Cloud Messaging）：認証・データ保存・通知配信のために利用します。
  • Sign in with Apple（Apple）：Apple ID を用いたサインインのために利用します。
  • Google AdMob（Google Mobile Ads SDK）：無料版での広告表示のために利用します。広告の配信・計測のため、広告識別子等の端末情報を Google が取得・利用する場合があります（上記 1.3 の ATT 許可設定に従います）。プレミアム（買い切り）を購入すると広告は表示されません。
  • Google Places API：ジム情報の登録（管理者機能）のためにサーバー側で利用します。一般ユーザーの位置情報を Places API に送信することはありません。
  • StoreKit（Apple）：プレミアム（買い切り課金）の購入・復元のために利用します。決済情報は Apple が処理し、当方はカード番号等の決済情報を取得しません。

各社のプライバシーポリシー:

  • Google: https://policies.google.com/privacy
  • Apple: https://www.apple.com/legal/privacy/

4. 情報の保存と削除

  • ユーザーが登録した情報は、アカウントが有効な間、上記サービス上に保存されます。
  • ユーザーは、アプリ内の「設定 > アカウントを削除」からいつでもアカウントを削除できます。 削除を実行すると、アカウント情報・アバター等のプロフィール・お気に入り・ホームジム・課題記録・投稿したレビュー・主催したセッション等の関連データが削除されます。Sign in with Apple を利用したアカウントの削除時には、Apple の連携（トークン）も失効させます。
  • 法令に基づき保存が必要な場合を除き、削除された情報は復元できません。

5. ユーザー生成コンテンツと安全対策

本アプリには、ユーザーが投稿するコンテンツ（レビュー・セッション募集）が含まれます。当方は、不快・違法なコンテンツおよび嫌がらせ行為に対して一切の許容をしません（ゼロトレランス方針）。

  • 各コンテンツのメニューから通報できます。通報されたコンテンツは確認のうえ、必要に応じて削除・アカウント停止等の対応を行います。
  • 迷惑なユーザーをブロックすることで、そのユーザーのコンテンツを非表示にできます。
  • 投稿時に不適切な表現の簡易フィルタを適用します。

詳細は本アプリの利用規約をご確認ください。

6. 未成年者の利用

7. 安全管理
